## 实际环境

- Linux x86_64，Python 3.9.23。
- PyTorch 2.5.0+cu121，torchvision 0.20.0+cu121，PyTorchVideo 0.1.5。
- PyAV 15.1.0，NumPy 2.0.2，OpenCV Python 4.12.0，ONNX 1.19.1。
- ONNX Runtime 1.19.2 在该环境实际仅提供 CPU／Azure provider；**没有验证 ONNX CUDA 推理**。代码会打印实际 provider，显式要求 CUDA 时不可用会报错。
- C++：GCC 11.4、OpenCV 4.11.0、CUDA Toolkit 12.1、TensorRT 8.6.1.6，NVIDIA GeForce RTX 3080。

已有 TensorRT engine 加载时提示跨设备模型可能影响性能或兼容性；本机合成输入运行成功，不代表可以在任意 NVIDIA 设备直接复用。原 C++ 使用的 TensorRT 8 binding API 有弃用警告，尚未迁移至新版本 API。

## 如何复现

```bash
python scripts/download_models.py
python scripts/smoke_test.py --device auto
python scripts/download_models.py --verify-only --include-historical
```

最后一条要求先使用 `--include-historical` 下载全部权重。`outputs/smoke/report.json` 记录最小运行验证结果；输出和合成视频不提交到 Git。C++ 编译命令见 [部署说明](DEPLOYMENT.md)。

## 验证边界

以上合成数据用于验证程序连接、视频解码和数值输出，不包含真实水蒸气／滴水标注，不能证明检出率、误报率或现场泛化能力。初始归档验证没有重新训练模型、完整复现历史训练，或验证 Mac／Windows 上的完整依赖环境。TensorRT Python 转换没有执行（原测试环境未安装其 Python 包），已有 ONNX 文件通过实际推理验证，新导出流程尚未执行完整转换回归。历史模型仅核对文件与配置，未逐个进行精度比较。

## 实时料袋检漏试验

新增实时模块的验证日期为 2026-10-16，使用同一服务器的独立临时目录。原始代码和模型没有修改。

- **20 项自动测试通过**：时间采样、内存预算、SDK 借用图像复制、完整网格覆盖、无运动仍分类、缓慢弱变化的参考定位、屏蔽填充、候选与确认状态、周期切换、断流后参考失效、旧结果过期、控制文件损坏／心跳超时，以及 SDK 转换失败时的缓存释放。
- 使用 12 秒、25 FPS、320×240 的合成视频按实际帧率回放；默认 5 秒窗口、12 FPS 缓存采样、48 帧输入、FP32 及水平翻转增强，原水蒸气 v8.1 模型在 RTX 3080 上输出 **8 次有效窗口结果**。
- 上述单个分类区域测试中，已接收到窗口末帧后的处理时间中位数约 **0.13 秒**，结果被主循环读取时的最大接收年龄约 **0.33 秒**。这不包含最初约 5 秒观察窗口，也不是相机端到端延迟；更多 ROI、更高分辨率、其他设备需要重新测量。
- 使用实际 X3D 推理和合成检测信号跑通 `idle → reference → reference_ready → inspect`；切到下一袋且没有参考时，未使用旧袋结果，也未为新袋输出有效判断。可通过 `scripts/verify_realtime.py` 复现。
- 训练入口使用合成视频执行 1 个 epoch，验证从原 checkpoint 载入权重、使用 `no_smoke/smoke` 类别并保存对应元数据。合成训练仅检查程序连接，数据没有真实标注意义；产生的测试权重没有作为烟雾模型发布。

**未验证：** 海康相机实机取图、具体 MVS SDK／相机型号兼容性、PLC 通信、现场生产节拍、真实料袋烟雾检出率、误报率和定位精度。MVS 取图缓存释放使用模拟 SDK 检查；没有把模拟测试记作硬件接入成功。现有水蒸气权重作为 `steam_proxy` 运行，不能当作已验证的料袋泄漏烟雾模型。生产部署前仍需现场采集和按检测周期划分的验证数据。
